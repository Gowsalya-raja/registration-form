# Registration Form Validation

## 📌 Overview
This project is a simple registration form developed using HTML and JavaScript. It allows users to enter their name, email address, and password, with JavaScript validation to check the input fields and display appropriate error messages.

## 🚀 Features
- **Name Validation:** Checks whether the name field is empty.
- **Email Validation:** Validates the email address format.
- **Password Validation:** Checks whether the password meets the required criteria.
- **Real-Time Validation:** Displays error messages for the respective input fields.
- **Form Submission:** Validates user inputs before submission.

## 🛠️ Technologies Used
- HTML5
- JavaScript
